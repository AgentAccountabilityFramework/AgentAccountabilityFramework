# Framework Governance

[Framework contents](README.md) · [Previous: Relationship to Standards](07-relationship-to-standards.md) · [Next: Appendix A](appendices/a-terminology.md)

Source: Section 8: Framework Governance.

The source marks this section as “to be developed” and describes internal review before publication. The governance model and mechanics of public contribution remain undefined.

Gravitee stewards the Agent Accountability Framework. Framework governance covers how versions are managed, how changes are reviewed, and how contributions are considered and decided.

The source describes a path from Gravitee's stewardship toward governance shared by multiple stakeholders or a home within a standards body. It identifies that direction without naming a receiving body or specifying a transfer process.

For work in this repository, use the [contribution guide](../CONTRIBUTING.md), [change proposal guide](../contributing/proposing-changes.md), and [repository governance](../GOVERNANCE.md). These explain how to propose and review repository edits. Changes to framework requirements must be identified as proposals until the source baseline is explicitly superseded.

The [release guide](../maintenance/releases.md) covers the checks for preparing a repository release. Decisions about framework versioning, governing bodies, and decision rights belong to framework governance; repository access alone does not establish those rights.
