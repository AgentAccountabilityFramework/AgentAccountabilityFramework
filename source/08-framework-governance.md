# 8. Framework Governance

[To be developed.] How the framework itself is governed: versioning and change process, how contributions are made and adjudicated, and the intended path from Gravitee’s stewardship to a multi-stakeholder or standards-body home. During the current pre-publication period, the framework is stewarded by Gravitee and reviewed internally; the governance model, including the mechanics of public contribution, will be defined before or alongside the first public release.
