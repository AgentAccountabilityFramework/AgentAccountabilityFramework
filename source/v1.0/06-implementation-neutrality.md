# 6. Implementation Neutrality

The framework defines what an accountable agent deployment must exhibit and takes no position on how it is achieved. It names no product, architecture, platform, protocol, or methodology, and conformance can never depend on one.

Where this document uses terms such as “enforcement layer,” “registry,” or “containment boundary,” they denote a property the organization must be able to demonstrate, not a component it must acquire. The means of satisfying any control are left entirely to the implementing organization.
